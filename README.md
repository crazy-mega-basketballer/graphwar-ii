# GraphWar II Clone

Математическая артиллерия - игра, где вы стреляете математическими формулами!

![Build Status](https://github.com/YOUR_USERNAME/gra/workflows/Build%20APK/badge.svg)

## 🎮 Описание

GraphWar II Clone - это игра, где вы управляете пушкой и должны попасть в цель, используя математические формулы для построения траектории выстрела.

### Особенности:

- ✨ **30 уникальных уровней** с прогрессивной сложностью
- 🎯 **Математические формулы** - стреляйте графиками функций
- 💥 **Разрушаемые препятствия**
- 🎨 **Современный дизайн** с анимациями
- 🔊 **Звуковые эффекты**
- 📐 **Локальная система координат** для каждого игрока
- 🎮 **Визуальный конструктор формул** - без клавиатуры!
- 🔍 **Zoom и Pan** - управление камерой
- ⬅️➡️ **Стрельба в обе стороны**

## 📱 Скачать APK

Перейдите во вкладку [Actions](../../actions) → выберите последний успешный запуск → скачайте APK из артефактов.

Или создайте Release для автоматической публикации APK.

## 🎯 Как играть

1. **Режим стрельбы:**
   - Составьте формулу с помощью кнопок (например: `x/10`, `sin(x/50)*100`)
   - Выберите направление: ← влево или → вправо
   - Нажмите FIRE
   
2. **Режим перемещения:**
   - Переключите режим переключателем
   - Введите формулу и расстояние Δx
   - Нажмите GO

3. **Цель:** Попасть формулой-траекторией в красную цель с перекрестием

## 🔧 Сборка локально

### Требования:
- JDK 17+
- Android SDK (API 24+)
- Android Studio (рекомендуется)

### Команды:

```bash
# Debug версия
./gradlew assembleDebug

# Release версия
./gradlew assembleRelease

# Установка на подключенное устройство
./gradlew installDebug
```

APK будут в: `app/build/outputs/apk/`
